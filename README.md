Simple Quiz App 📝

📌 Description

A simple and interactive Quiz App built using HTML, CSS, and JavaScript that allows users to answer multiple-choice questions and view their final score.

🎯 Purpose

The purpose of this project is to practice HTML, CSS, and JavaScript fundamentals and understand how JavaScript can be used to create interactive web applications.

🛠️ Technologies Used

HTML

CSS

JavaScript

✨ Features

Multiple-choice questions

Interactive answer selection

Automatically calculates the score

Displays the final score after completing the quiz

Simple and responsive user interface



🚀 How to Run

Download or clone this repository.

Open the index.html file in a web browser.

Select an answer for each question.

Click the Next button to continue.

View your final score at the end.
